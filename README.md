# 青年媒体中心官网

中北大学青年媒体中心展示网站，包含首页与摄影、设计、抖音、采编、运营、微信、综合发展七个部门页面。

- 正式网站：https://nuc-ymc.com
- 技术：React 18、TypeScript、Vite、Tailwind CSS、React Router。
- 部署：阿里云 OSS 香港，支持单页应用路由回退。

## 本地运行

使用 Node.js 20.19+（已验证 Node.js 24）：

```sh
npm ci
npm run dev
```

生产构建与预览：

```sh
npm run build
npm run preview
```

构建产物输出到 `dist/`。部署及 HTTPS 证书维护见 [部署指南](部署指南-阿里云OSS香港.md)。

## 内容维护

- `src/data/site.ts`：首页文案、部门入口、统计数字、联系方式。
- `src/data/`：部门内容、图片分类与媒体清单。
- `src/pages/`：首页与各部门页面。
- `public/assets/`：网站实际使用的图片、视频及二维码。
- `tools/`：证书检查、续签工具及离线测试。

部分统计数字和说明文字仍为占位内容，发布新内容前请核实。素材清单与方案确认书保留早期规划；当前实现以源码和部署指南为准。

## GitHub 上传基线

首次上传来自本地已验证提交 `7696dae`。原本地历史包含超过 GitHub 单文件限制的原始视频，因此本仓库从当前可部署版本建立独立基线；原始本地历史和素材保留。

仓库包含网站所需的完整源码和发布用素材；不包含原始视频、工具安装包、构建产物、OSS 凭据、证书私钥或本机配置。克隆后运行网站无需云服务凭据；执行证书续签时才需在本机另行配置 `ossutilconfig`。

本地原项目的 `master` 保留完整旧历史；上传工作目录位于 `.cache/github-upload`，使用 `github-main` 分支，对应 GitHub 的 `main`。后续同步使用该分支，避免将含超限原始素材的 `master` 直接推送到远端。
